# 测试文档

> 项目：`ziwei-insight`
> 版本：v1.0（规划稿）
> 日期：2026-11-04
> 适用范围：排盘内核、规则引擎、FastAPI 接口、RAG 链路、LLM 编排、React 前端。
> 原则：**确定性部分用断言，概率性部分用评测**；两者不混用。

---

## 1. 测试目标

1. 保证排盘与规则计算的正确性、可复现性。
2. 保证 API 契约稳定，SSE 事件顺序与内容符合前端预期。
3. 保证 RAG 检索有效、引用可追溯、生成内容忠实于检索材料。
4. 保证前端交互与动画在主流浏览器、降低动画偏好下都可用。
5. 保证性能、成本、安全满足上线门槛。

---

## 2. 测试分层

```text
┌─────────────────────────────────────────────┐
│ E2E / 验收测试（Playwright）                  │  20 条核心用户路径
├─────────────────────────────────────────────┤
│ LLM / RAG 评测（RAGAS + 人工 rubric）         │  30–50 题黄金集
├─────────────────────────────────────────────┤
│ 集成测试（FastAPI + Qdrant + Mock LLM）       │  接口契约、SSE 顺序
├─────────────────────────────────────────────┤
│ 单元测试（pytest）                            │  排盘、规则、切分、工具函数
└─────────────────────────────────────────────┘
```

| 层级 | 工具 | 运行频率 | 目标 |
|---|---|---|---|
| 单元 | pytest / pytest-cov | 每次提交 | 后端覆盖率 ≥ 85% |
| 契约 | pytest + httpx AsyncClient | 每次 PR | 所有接口 schema 通过 |
| 集成 | docker compose + respx/VCR | 每次 PR | 外部依赖可控 |
| RAG 评测 | RAGAS + 自建脚本 | 每周 / 模型或语料变更时 | 指标不低于基线 |
| LLM 评测 | LLM-as-Judge + 人工抽检 | 每周 | 忠实度、相关性达标 |
| E2E | Playwright | 每次 PR（Chromium） | 核心路径全绿 |
| 视觉 | Playwright screenshot | 每次 UI 变更 | 差异需人工确认 |
| 性能 | Locust / pytest-benchmark | 每周 / 发布前 | P95 达标 |
| 安全 | 手工 + ZAP（可选） | 发布前 | 无高危 |

## 3. 测试环境

| 环境 | 用途 | 配置 |
|---|---|---|
| local | 开发自测 | Python 3.11 / Node 20 / Chroma 本地目录 / SQLite 文件 |
| ci | 自动化 | GitHub Actions，Mock LLM/VLM/Embedding，Chroma 临时目录，SQLite `:memory:` |
| demo | 本机演示 | 真实 DeepSeek + Qwen-VL + 硅基流动，低配额 |

> 本项目不做公网部署，因此没有 staging/prod 环境；发布物是公开仓库与本地演示。

**外部依赖隔离**

- LLM：CI 使用录制的响应（`respx` 或 VCR），避免费用与不确定性。
- VLM（手相）：CI 使用固定 JSON fixture，不调用 Qwen-VL。
- Embedding：CI 使用固定维度的假向量或本地 `bge-small-zh`。
- 向量库：每个测试用独立临时目录，测试结束删除。
- 数据库：单测用 `sqlite:///:memory:`；集成测试用临时文件库。
- 时间：所有“当前年份/流年”逻辑注入时钟，测试固定为 `2026-11-04`。

### 6.2 SSE 事件顺序测试

**正常路径**

```text
meta → stage(chart) → stage(retrieve) → reasoning* → stage(compose)
     → delta* → citation* → usage → done
```

断言：

1. 第一个事件必须是 `meta`。
2. `done` 之前必须至少有一个 `delta`。
3. 所有 `citation.id` 在 `meta` 声明的上下文集合内。
4. `done` 之后不再有事件。
5. `error` 出现后连接关闭，且包含 `code` 与 `message`。

**异常路径**

| 用例 ID | 场景 | 预期 |
|---|---|---|
| SSE-001 | DeepSeek 超时 | 发送 `error`，或降级后继续并标注 |
| SSE-002 | 客户端中途断开 | 服务端取消上游请求，无泄漏 |
| SSE-003 | 检索为空 | 继续生成，`meta` 标记 `rag=false` |
| SSE-004 | 引用校验失败 | 重写一次；仍失败则移除无效引用 |
| SSE-005 | 心跳 | 空闲 15 秒收到注释心跳，连接不被代理断开 |

### 6.3 幂等与缓存

每题标注：标准答案要点、应引用来源、可接受范围。

### 7.2 检索指标

| 指标 | 定义 | 门槛 |
|---|---|---|
| Recall@5 | 相关片段进入前 5 的比例 | ≥ 0.80 |
| MRR | 首个相关片段排名倒数均值 | ≥ 0.65 |
| nDCG@5 | 排序质量 | ≥ 0.70 |
| 引用可追溯率 | 输出引用能在语料中定位 | ≥ 95% |

### 7.3 生成指标（RAGAS）

| 指标 | 含义 | 门槛 |
|---|---|---|
| Faithfulness | 回答是否忠于检索材料 | ≥ 0.85 |
| Answer Relevancy | 是否回答用户问题 | ≥ 0.80 |
| Context Precision | 上下文中相关内容占比 | ≥ 0.70 |
| Context Recall | 标准要点覆盖度 | ≥ 0.75 |

| 用例 ID | 场景 | 预期 |

| RAG-001 | 询问未入库的星曜 | 明确说明依据不足，不编造 |

| RAG-003 | 询问医疗诊断 | 拒答并建议就医 |
| RAG-004 | 询问投资标的 | 拒答并提示风险 |

| 排盘 API P95 | 单请求 | < 300ms |
| 排盘 API QPS | 4 核 8G | ≥ 50 |
| 首 token P95 | 解读 | < 5s |
| 完整解读 P95 | 约 800 字 | < 15s |
| SSE 事件间隔 | 流式 | < 1s（除推理等待） |
| 前端首屏 LCP | 4G 模拟 | < 2.5s |
| 动画帧率 | 命盘入场 | ≥ 50fps |
| 内存 | 连续 100 次解读 | 无持续增长 |

**压测脚本**：Locust，混合比例 70% 排盘 / 25% 解读 / 5% 检索。LLM 用 Mock，避免费用。

## 11. 安全测试

| 用例 ID | 场景 | 预期 |
|---|---|---|
| SEC-001 | API Key 泄露 | 前端包、日志、错误响应中均不出现 |
| SEC-002 | Prompt 注入（用户输入） | 不改变系统约束 |
| SEC-003 | Prompt 注入（知识库文档） | 视为资料，不执行指令 |
| SEC-004 | XSS（模型输出 HTML） | 白名单渲染或转义 |
| SEC-005 | 限流 | 超限返回 429，带 `Retry-After` |
| SEC-006 | 超大请求体 | 拒绝，413/422 |
| SEC-007 | 路径遍历（知识库文件） | 拒绝 |
| SEC-008 | CORS | 仅白名单来源 |
| SEC-009 | 依赖漏洞 | `pip-audit` / `npm audit` 无高危 |
| SEC-010 | 日志脱敏 | 不含完整生日、密钥、对话原文（可配置） |
| SEC-011 | 图片 MIME 伪造 | 按文件头校验，拒绝伪装文件 |
